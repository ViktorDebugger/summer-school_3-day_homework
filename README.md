# summer-school_3-day_homework

![CI](https://github.com/ViktorDebugger/summer-school_3-day_homework/actions/workflows/ci.yml/badge.svg)

FastAPI project created as homework for Day 3 of the Git/GitHub summer school course.

## Setup and run

```
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Tests

```
pytest
```
